# Like Chat 标志资产（矢量重绘）

参考图：1254×1254 透明 PNG（深蓝圆角方块底 + 白色 D + 电光蓝 S（带鲸尾/波浪感）+ 左侧蓝色聊天气泡（三个白点）+ 底部 "Like Chat" 字标）。

本目录的 SVG 是**手工重绘的矢量版**：D / S / 气泡的轮廓按参考图逐像素等值线（marching squares）提取，再用 Douglas-Peucker + 保角 Catmull-Rom 平滑成贝塞尔路径；背景与各元素的渐变按参考图逐点采样，拟合成 9 段线性渐变；字标用系统字体 Segoe UI 排版（不是路径）。
所有 PNG 都是由本目录里的 SVG **文件本身**用 `@resvg/resvg-js` 渲染的，与 SVG 一一对应，可直接使用。

## 4. 字标排版（SVG 里的 `<text>`）

| 项 | 值 |
|---|---|
| 字体栈 | `Segoe UI, Segoe UI Black, Arial, sans-serif`（无外部字体文件、无 `@font-face`） |
| "Like" | `font-weight="800"`（落到 Segoe UI Black），`font-size 157.43`，`x=297.98`，`baseline=973`，`letter-spacing=-0.37` |
| "Chat" | `font-weight="700"`（落到 Segoe UI Bold），`font-size 157.43`，`x=622.7`，`baseline=975`，`letter-spacing=0.18` |

用 resvg 实测过：`Segoe UI` 在 weight 800 上正确落到 Segoe UI Black，文字能渲染出来（不是丢字体）。
两词的 x / baseline / 字距都是按参考图的 ink bbox 反推校准的，**渲染后的 ink bbox 与参考图差 ≤2px**：
Like `x 309–607 / y 857–973`、Chat `x 629–957 / y 858–975`。

> ⚠️ 字标是 `<text>`，**依赖系统字体**。本机 Windows 有 Segoe UI，所以 PNG 已按此栅格化、不受影响；
> 但若要把 SVG 拿到没有 Segoe UI 的环境（Linux/CI/部分 Android WebView）渲染，会退化成 Arial/sans-serif（更细、更宽）。
> 需要 100% 可移植的话，把两个字标改成路径（或直接使用本目录 PNG）。

## 5. 与参考图的差异（已知，按影响排序）

1. **字标是"同族字体近似"，不是路径**：参考图的字形不是 Segoe UI——它的 `L` 脚更长、`C` 更窄更圆、整词比 Segoe 宽一点；且参考图里 "Like" 明显比 "Chat" 粗（笔画 27px vs 23px），所以这里 "Like" 用 Black(800)、"Chat" 用 Bold(700) 来还原这个粗细差。**位置/字号/字距已对齐，单字轮廓仍有肉眼可见差别**（字标区 MAE 最大，是整图误差的主要来源）。
2. **渐变是线性近似**：S 的"蓝→青"在参考图里有一点沿笔画走向的味道，这里用一条约 39° 的线性渐变 + 9 段色标近似。逐点采样误差多在 **±8/255**，最差两点（S 左右两肩）约 **±19/255**。
3. **背景右上略亮**：参考图最亮处是右上角 `#032b81`；`mark.svg` 满幅背景会把渐变端色延伸到画布边缘，右上角比 lockup 版再亮一点（有意为之，满幅时观感更均匀）。
4. **边缘更干净、无 ai 噪点**：参考 PNG 整体 alpha 是 252–253（不是 255），轮廓边缘有 1–2px 抗锯齿/生成噪点，圆角外还带一圈 1px 的蓝色描边残留；矢量版是纯 alpha=255 的干净边缘。矢量轮廓取的是参考图等值线的中位线，因此有 1–2px 的轮廓偏差。
   整体量化：与参考图逐像素 **MAE = 5.52/255，P95 = 10.3/255**（仅在 alpha>128 的不透明区域统计）。
5. **参考图 "Chat" 的基线比 "Like" 低 2px**（原图排版残留），本重绘保留了这个 2px（baseline 973 vs 975）。
6. **两处有意的结构改动**：`mark.svg` / `mark-foreground.svg` 不含字标；`mark.svg` 背景改为满幅（参考图版本带 8% 透明外边距）。这是为了小图标能占满画布。
7. 气泡的尾巴、S 的上下鲸尾这些极尖处，参考图有 1–2px 的三角形抗锯齿衰减，矢量版按几何中位线取尖点，因此尖角比参考图略"实"。

## 6. 使用建议 / 小尺寸验证

- **Windows / 桌面图标**：用 `mark-192.png`；做 `.ico`/`.icns` 时用 `mark.svg` 渲染多档位图（16/24/32/48/64/128/256）。
- **Android 自适应图标**：前景用 `foreground-*.png`（或 `mark-foreground.svg`），背景层用深蓝底——直接复用 `logo-lockup.svg` 里的 `bgGrad`，或纯色 `#0A1029`；**不要用浅色背景**。
- **关于页 / 启动图 / 商店图**：用 `logo-1254.png`（或 `logo-lockup.svg`）。
- **网页 favicon**：`mark-48.png`，或 `<link rel="icon" href="mark.svg">`（现代浏览器支持 SVG favicon）。

小尺寸实测（已用 `read_image` 目视 + 像素量测确认）：

| 尺寸 | 结论 |
|---|---|
| 192px | DS 与气泡细节清晰；内容左右各留 12px、上下各留 46px。 |
| 48px | **DS 仍可辨认**：白色 D 的"开口环 + 左竖条"、蓝色 S 的鲸尾轮廓都能读出；气泡内三个白点并成一排亮点（作为装饰可接受，非必须）。无贴边裁切：内容距左边/右边各 3px、上 11px、下 12px。 |
| 24px | DS 整体形状可读，白点已融入气泡（正常现象）。 |
| 16px | 只能分辨"左白右蓝"两团，属极限尺寸；已把 mark 内容放大到 87.7% 宽度来尽量补救。 |
| 前景层 | 内容宽 64.4%、高 38–39%，左右安全边距 17.6–17.8%、上下 30–31%——落在 108dp 画布中间 66dp 安全区内（安全区要求 ≤ 63.8% 宽，实测 64.4% 含 1px 抗锯齿外扩，几何本身是 63.9%）。 |

## 7. 可复现性

- 三份 SVG 自成一体：只用 `rect` / `path` / `circle` / `text` 和 `<defs>` 里的线性渐变，**无外部引用**（无 `href`、无 `@font-face`、无远程 `url()`），可以离线任意缩放。
- PNG 的渲染方式：以 `@resvg/resvg-js` 打开对应 SVG，`fitTo: { mode: 'width', value: N }`、透明背景，输出 PNG。
- 修改配色：直接改 `<defs>` 里对应 `linearGradient` 的 `stop-color` 即可（`bgGrad` / `dGrad` / `sGrad` / `bubbleGrad` / `likeGrad` / `chatGrad`）；改字：改 `<text>` 的内容与 `x` / `letter-spacing`。
